# Public Showcase Security Review

## 1. Objective

This document defines the privacy and security criteria used for the public showcase repository.

## 2. Exclusion Rules

The public repository must not contain:

- `.env` files.
- Environment variables with real values.
- API keys.
- Supabase project URLs.
- Supabase anonymous keys.
- Supabase service-role keys.
- Vercel project URLs.
- Production deployment URLs.
- Customer names.
- Student names.
- Phone numbers.
- Addresses.
- Payment records.
- Operational exports.
- Screenshots with real records.
- Local machine paths.
- Internal workspace paths.
- Private issue references.

## 3. Safe Content

The public repository may contain:

- General product description.
- Conceptual architecture.
- Sanitized module descriptions.
- Roadmap.
- Portfolio positioning.
- Placeholder screenshots.
- Non-production diagrams.
- Non-sensitive technology stack.

## 4. Current Status

This repository is safe for public portfolio use because it contains documentation only and no production source code or operational data.
