# Product Roadmap

## Phase 1 — Operational Stabilization

- Improve order registration speed.
- Reduce vertical scrolling in high-frequency views.
- Improve daily menu validation.
- Strengthen admin and operator role separation.
- Add clearer order and payment status indicators.

## Phase 2 — Reporting

- Add daily order dashboard.
- Add payment summary dashboard.
- Add export to Excel.
- Add export to PDF.
- Add order volume by institution / company.
- Add recurring diner reports.

## Phase 3 — Automation

- WhatsApp-assisted order intake.
- Message parsing for structured order capture.
- Duplicate order detection.
- Missing order alerts.
- Payment reminder automation.

## Phase 4 — Costing & Margin Control

- Ingredient cost catalog.
- Portion costing.
- Packaging cost tracking.
- Weekly cost projection.
- Margin by menu type.
- Margin by customer segment.

## Phase 5 — AI-Assisted Operations

- Demand forecasting.
- Suggested purchasing quantities.
- Menu planning recommendations.
- Anomaly detection in order patterns.
- Operator assistant for daily workflow.
